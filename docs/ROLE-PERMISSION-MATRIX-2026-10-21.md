# Ero Models — matriz de papéis e permissões

**Status:** baseline para revisão do responsável e compliance.  
**Regra:** a UI nunca concede acesso; cada procedure/API deve repetir sessão, papel/capability, ownership, estado e regra operacional.  
**Papéis persistidos atuais:** `user`, `admin`, `super_admin`, `dev`. Titularidade de anúncio continua sendo `profiles.ownerId`; não se deve inferir privilégio administrativo de ser titular.

## Convenções

- **Público:** não exige conta, mas fica atrás dos gates de idade/publicação e só recebe dados sanitizados.
- **Cliente:** capacidade de uma conta autenticada para salvar, bloquear, denunciar e gerenciar preferências próprias.
- **Titular:** relação de ownership ou delegação explícita sobre um perfil/mídia.
- **Moderador, financeiro, analista, suporte e auditoria:** funções operacionais propostas; não devem ser simuladas como roles persistidos antes de aprovação do modelo de bootstrap/migração.
- **Dev/super_admin:** privilégio explícito, nominativo, auditado e com MFA/step-up para alto impacto. O modelo atual ainda não comprova MFA; portanto, esta linha é requisito de liberação, não alegação de que já esteja pronto.

## Estado da implementação

1. O backend já possui procedures públicas, autenticadas, protegidas e administrativas; ownership de perfil/mídia é validado em caminhos principais.
2. A branch desta evolução alinha a allowlist `ADMIN_EMAILS` verificada com o redirecionamento de login, a guarda visual do admin e as rotas HTTP de upload/preview. O papel persistido não é promovido automaticamente.
3. A área de cliente usa somente `ctx.user.id` para favoritos, bloqueios e denúncias próprias; não há leitura de dados de outra conta.
4. Moderador, financeiro, analista, suporte e auditoria ainda não são um RBAC completo no schema. Implementá-los exige decisão de negócio, migração/compatibilidade, bootstrap e testes negativos por procedure.
5. MFA, step-up, logs imutáveis e dupla aprovação financeira continuam **bloqueados por decisão/implementação**. Nenhuma UI deve sugerir que esses gates já estão satisfeitos.
